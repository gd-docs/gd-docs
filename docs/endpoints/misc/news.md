# news.dat

## Requests

In Geometry Dash 2.209, the news feed has been added. The feed can be fetched via a GET request to `https://geometrydashfiles.b-cdn.net/news/news.dat`.

You can fetch the latest version of the news feed by sending a GET request to `https://geometrydashfiles.b-cdn.net/news/news_version.txt`.

The news format is covered [here](/resources/client/news.md).
